## 🚀 Projeto em destaque

### 🚗 [Detecção de placas veiculares com YOLOv8n](https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO)

Treino do zero vs. fine-tuning a partir do COCO, com 3 sementes por modelo e o mesmo orçamento de treino.

| | Do zero | Fine-tuning |
|---|---|---|
| mAP@0.5:0.95 (validação) | 0,623 ± 0,011 | **0,698 ± 0,005** |
| mAP@0.5:0.95 (imagens com 2+ placas) | 0,085 ± 0,022 | **0,252 ± 0,024** |

> Achado principal: o teste saturava porque só tinha imagens com uma placa. Estratificando a validação, o pré-treino triplica o desempenho no cenário ausente do treino.
